# Bundled invoice fonts

`latin-modern/` contains the unmodified Latin Modern Sans 10 OpenType regular,
bold, oblique, and bold-oblique faces from Latin Modern 2.005. They are bundled
with the macOS app so invoice layout does not depend on fonts installed on the
recipient's computer. Linux development continues to use its existing font setup.

Authors: Bogusław Jackowski and Janusz M. Nowacki, based on Donald E. Knuth's
Computer Modern. The GUST Font License and the upstream family README accompany
the fonts. Source: <https://www.gust.org.pl/projects/e-foundry/latin-modern>.
